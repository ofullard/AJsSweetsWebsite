# AJsSweetsWebsite

A responsive web design demonstration project showcasing modern web development practices for a fictional sweets/confectionery business.

## 📋 Overview

This project is an ASP.NET web application designed to demonstrate responsive web design principles and techniques. It serves as a practice project for building mobile-friendly, adaptive websites that provide optimal viewing experiences across a wide range of devices.

## 🚀 Features

- **Responsive Design**: Adapts seamlessly to different screen sizes (desktop, tablet, mobile)
- **Modern UI/UX**: Clean and intuitive interface for browsing sweet products
- **ASP.NET Framework**: Built with ASP.NET for robust server-side functionality
- **Cross-browser Compatible**: Works across major web browsers

## 🛠️ Technology Stack

- **Backend**: ASP.NET
- **Frontend**: HTML5, CSS3, JavaScript
- **Styling**: Custom CSS with responsive design patterns
- **Dependencies**: Bootstrap, Popper.js, jQuery

## 📁 Project Structure

```
AJsSweetsWebsite/
├── AJsSweets.Web/       # Main web application
├── AJsSweetsApp/        # Application logic
├── AJsSweetsData/       # Data layer

```

## 💻 Getting Started

### Prerequisites

- Visual Studio 2015 or later
- .NET Framework
- IIS or IIS Express

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ofullard/AJsSweetsWebsite.git
   ```

2. Open the solution file:
   ```
   AJsSweetsWebsite.sln
   ```

3. Restore NuGet packages in Visual Studio

4. Build the solution:
   - Press `Ctrl+Shift+B` or
   - Go to Build > Build Solution

5. Run the project:
   - Press `F5` to run with debugging, or
   - Press `Ctrl+F5` to run without debugging

## 📱 Responsive Design Features

This project demonstrates key responsive design principles:

- **Fluid Grid Layouts**: Flexible grid systems that adapt to screen size
- **Flexible Images**: Images that scale appropriately within their containers
- **Media Queries**: CSS breakpoints for different device sizes
- **Mobile-First Approach**: Optimized for mobile devices with progressive enhancement
